## 3. 上游稳定性：具体为什么被挡住

实际代码门槛：SPURS multi 首选 ≤0.5 kcal/mol、review ≤1.0；FoldX 组合 ≤2.0；两者绝对差 ≤1.5。严格路线 FoldX shortlist 只接收初筛状态 `SPURS_ONLY_REVIEW_REQUIRED`，这个状态实际上要求 SPURS ≤0.5。

| 子类型 | 数量 | 直接拒绝机制 |
|---|---:|---|
| SPURS 在 (0.5,1.0]，无 FoldX | 39 | 未进入 FoldX，最后 COMBINATION_REJECT |
| SPURS >1.0，无 FoldX | 5 | 同上，预测风险更高 |
| 两模型各自稳定门都通过，但差值 >1.5 | 17 | MODEL_DISAGREEMENT 优先于 CONSENSUS_PASS |
| FoldX >2.0，且预测分歧 | 4 | 存在 FoldX 风险信号；仍不能称实验不稳定 |

例如 A41Y/T124R 的 SPURS 为 −0.0311、FoldX 为 −2.5557，两者均预测允许或有利，但因为差值 2.5245 被拒绝。Q76W/D100R 为 +0.3781/−1.2699，也因为 1.6479 的差值被拒绝。相反，E59F/L141W 的 FoldX 为 +10.2649，应保留高风险阻断，不能把所有分歧一并放行。

**判断：**保持结构稳定是必要目标；固定的 0.5/2.0/1.5 是项目风险政策，不是第一性原理常数。39 个 review 范围候选没有任何独立 FoldX 结果，不能称它们经过双模型确认不稳定。对17个“两个模型都过门但幅度分歧”的候选，当前绝对差硬门会惩罚更负的稳定性预测，其物理解释弱于“一个模型明确预测强烈去稳定化”。

**建议：**正式门维持原合同，新增有界 review 实测队列，先给 0.5–1.0 边界组和双方均过门的分歧组补独立证据。把“双方支持但幅度分歧”与“稳定/去稳定方向冲突”分开记录；根据重复分布、结构质量、独立验证集和最终实验稳定性决定新合同，而不是直接提高阈值。也不能把同一 FoldX 重复的离散度当作预测相对实验的模型误差。

FoldX 原始论文和 SPURS 官方实现均提供预测方法与适用范围，但并不确立本项目这三个阈值，更不证明 CTLA4 双点预测的误差已被控制。[FoldX 原始论文](https://pmc.ncbi.nlm.nih.gov/articles/1160148/)、[SPURS 官方实现](https://github.com/luo-group/SPURS)。

代码：`joint_design_v4/engine.py:426–445,1214–1219`；配置 `config.py:118–132`。

## 4. 最大下游损耗：全结构拓扑变化使所有通道失效

`surface_perturbation/fields.py:150–154` 比较整个 WT/Mut SES 网格的 Euler characteristic。只要不同，该次模型 **所有变化通道置 NaN**，包含几何、原子占据和化学描述。然后逐位确认无法累计有效改变。

当前 21 个逐位未确认候选中，有 18 个在前五次至少两次触发这一条件。例如：

| 候选 | 前五次拓扑拒绝 |
|---|---:|
| A41Y/K65W | 5/5 |
| E59T/A61W | 5/5 |
| A41R/V151I | 4/5 |
| A44E/A61W | 4/5 |
| A41Y/Q148R | 2/5 |
| A41Y/S62R | 2/5 |
| E59T/A61W/M91W | 3/5 |

这说明 `MUTATION_SITE_NO_VERIFIED_CHANGE` 常常是无法验证，而不是在可靠有限观测下证明无变化。

**判断：**破洞、错误法向、配准失败或局部表面投影不可靠必须阻断依赖它们的证据。但“整个分子 Euler 不同”不能直接推导“所有局部化学差值、原子占据和 SDF 均不可比较”。在固定 WT 查询坐标下，两个闭合表面的 SDF 本身可以有不同拓扑；拓扑变化可能是实际局部扰动，也可能是离散网格伪影。当前一刀切传播到全部通道，是需要优先验证的设计缺陷。

保存证据 `saved_ses_resolution_audit.json` 已有 **11 个相同原子构型的粗/细网格比较，10 个 Euler 不一致**，而两种网格均闭合。例如同一构型粗网格 Euler −4，细网格 +4。它证明此判定对网格分辨率敏感，不证明所有 WT/Mut 拓扑变化都是伪影，也不授权直接放行。

**建议：**拆开网格有效性、拓扑变化和局部对应资格。以局部查询支撑、投影唯一性、法向质量、粗细网格误差和连通分量归属审查依赖表面投影的通道；原子占据、标量化学和表面方向分别审核，禁止把一个全局诊断传播成全部通道失效。真实破洞和局部对应歧义仍保持未知。先用保存模型建立通道依赖表和同查询对照，确认有效掩码的来源，再版本化修复。

## 5. “同四次／五次”与“五次全部有限”的额外门槛

`calibration.py:53` 要求前五次值全部有限；`directions.py:44` 对联合向量同样要求五次全部有限。随后才判断至少四次超过阈值。因此现行规则是 **五次全部可用 + 至少四次阳性**，强于一般意义的四次阳性。

零求解逻辑重放：阈值 1、校准有效时，`[2,2,2,2,0]` 判阳性，`[2,2,2,2,NaN]` 判未知且无阳性。第五次未知没有被填零，但已经明确的四次阳性也整体消失。

**判断：**如果用户合同要求“五次都能被完整解析”，该额外门是有意保守政策；如果合同是“五对真实模型中，同四次直接支撑并超过阈值”，它并非这个命题的逻辑必要条件。四个可靠阳性可以支撑一个至少四次成立的下界，第五次仍保留未知，不能声称五次完整。

**建议：**明确 quorum 的资格语义：五对模型身份必须存在，所选同四次必须逐点有限、支撑一致、校准合格且向量方向一致；第五次未知单独报告。禁止按结果追加模型再挑最有利四次；前五次身份冻结、失败与未知全部保留。改动需新合同，不直接覆写正式五次完整性规则。

## 6. 为什么已有阳性还不能进入正式池

`calibration_scope.py:37` 要求局部支撑上 **每一个声明的标量/联合向量通道，在每一个要求点都有效**。正式资格要求：这个全通道 scope 完整且观测完整，或者所有可能新增扫描范围的上界已经闭合。后一个例外已存在，不能说当前代码绝对没有替代路径。

然而阳性分类 `classification.py` 使用通道的逻辑并集：某个通道可靠超过阈值即可确认改变。于是，“存在可靠阳性”和“所有可能阳性完全解析”被合并到同一个构建体资格门。

| 逐位阳性候选 | 所有局部点至少一个通道可解析 | 全通道完整 | 观测局部完整 | 未闭合扫描上界面积 Å² |
|---|---:|---|---|---:|
| D78A/M122W | 100% | 是 | 是 | 17.36；通过完整 scope 路径 |
| A41Y/L47R | 100% | 否 | 是 | 24.83 |
| V81W/D100F | 100% | 否 | 是 | 110.47 |
| V81W/D99V | 100% | 否 | 是 | 115.59 |
| E59R/M91W | 100% | 否 | 是 | 81.45 |
| E59T/M91W | 100% | 否 | 是 | 158.46 |
| M91W/Q111R | 100% | 否 | 是 | 77.62 |
| T104W/Q111R | 100% | 否 | 是 | 189.29 |
| A41Y/A61R | 98.05% | 否 | 否 | 73.62 |

“所有点至少一个通道可解析”不是所有点阳性，不是所有通道解析，更不是整个分子已解析。上表的上界面积是可能未确认的扫描机会面积，不应改称真实未知直接扰动面积。T104W/Q111R 的多数失败通道已在局部达到约98.7%–99.8%解析，但仍未满足全点完整。

**判断：**若要宣称所有通道、整个局部足迹都已解析，当前门合理；若目标是仅用已确认阳性区域计算保守扫描下界，则其他通道/位置尚未解析不必推翻已确认阳性。未知会阻止阴性与完整性结论，不应自动否定另一个独立通道的有效阳性。这是本轮产出受限的核心合同问题。

**建议：**独立保留三种状态：逐位已确认阳性、局部全通道完整、全搜索/APBS闭合。在新的正式下界合同中，只有经过校准与重复规则的阳性区域进入覆盖，其他点保持未知；仍使用同一分母、12 Å 扫描核、稳定门和4–12项预算。先在保存结果上与原合同并列审核，本轮继续 shadow，不回写现有正式状态。

79.381610% shadow 不能被保证转成新合同的正式覆盖：其阈值多重比较和经验噪声校准仍需独立验证；即使原样接受，也仍差0.618390个百分点，不能四舍五入宣称80%。

## 7. null 分位数规则：少量重复不等于统计闭合

现有 null 来自相邻 WT 模型差值，N 个模型得到 N−1 个 block；20 模型只有19 block，而且相邻差值共享 WT，存在依赖。阈值取经验 q95 与数值敏感性量的较大值。稳定判定是前半 block 的 q95 与全部 q95 的差，不超过数值量或 q95 的10%。

这是一种工程收敛诊断，代码也明确写着“不构成假阳性控制”。在默认线性分位数定义下，19 个样本的 q95 主要由最顶部两个观测决定；前半9个 block 的尾部更稀疏。[NumPy 官方分位数定义](https://numpy.org/doc/stable/reference/generated/numpy.quantile.html)。同一总体95%分位附近，19个独立观测的期望尾部数量也仅0.95；本项目还不是独立观测，因此不能借这个数量主张置信区间已成立。

此外，`calibrate_channel` 要求该点所有 null block 都有限：一次未知即可阻断完整校准。大量点×多个通道的“全部都通过10%判据”，比单点经验 q95 稳定困难得多。5→10→20之后仍未知，不自动意味着突变无效；达到上限也不能保证以后不可能收敛。

**建议：**保留 matched scope 和数值敏感性，使用保留依赖关系的 WT 模型重采样/成组校准，报告分位数不确定区间；按“足以决定阳性下界、足以影响面板”的需求停止。全通道并集要有联合 null 或明确多重比较策略，避免将多通道逐个95%阈值误称整体95%可信。联合校准必须处理通道单位和相关性，不能直接将不同单位的原值取最大。

当前粗细网格差、舍入与替代投影差是观测到的数值敏感性指标，不是经过证明的绝对误差上界；不能据此声称覆盖下界已有严格统计覆盖率保证。建议先证明新方案在 WT-null holdout 上的表现，再考虑提高最大重复数。单纯20→100不解决确定性未知、全局拓扑否决和资格逻辑错配。

## 9. 额外调度设计缺口

当前 `resume_batches` 的后续批次只有 `goal_status == ACHIEVED` 才调用 `triple_test`（`run_ctla4_coverage_v2.py:1062`）。早期确实测过一个三点，不能称从未做三点；但后续未达目标时缺少持续三点补盲入口。这与“未达标时按实际收益安排双点或三点补盲”的原计划不完全一致。

建议先解决双点公共证据瓶颈，再按已测父双点、盲区实际增益和三个精确对照成本调度三点补盲；达到目标后才考虑压缩。应同时排除已完成或已确定失败的同一三点身份，不能机械重复唯一早期失败三点。

## 10. 建议修改次序与低成本验证

1. **诊断拆分，零新模型。** 为每个位点/通道记录“有限且未超阈值”“拓扑导致无效”“数值量缺失”“统计未稳定”“质子化/方向未知”；不能统一显示无变化。本次已给出96行审查表，但还需产品状态细分。
2. **局部拓扑与通道依赖，先保存模型重放。** 从拓扑拒绝高发组和唯一正式组取固定模型；比较原子占据、化学、SDF、法向的独立有效性，保留全局Euler诊断。已有粗细网格优先复用，不新增FoldX。
3. **冻结四次资格合同，纯逻辑与同模型验证。** 覆盖四阳性一未知、三阳性两未知、不同四次支撑、向量方向冲突、缺校准、未知点不填零等反例；不能挑选五次以外的有利模型。
4. **下界资格与全场完整性分开，继续shadow对照。** 同一候选、模型、查询、分母、核、稳定门，逐项核验新/旧覆盖差异来自哪条资格规则。未解析区域不计覆盖。
5. **统计合同验证。** 用 WT-null 留出与联合通道误判审计，检查新阳性判据的稳定性和重复选择偏差；没有这个验证，不能把工程性宽松称科学提升。
6. **小规模稳定性review。** 有界选择SPURS边界和双方过门的分歧组，补缺失的独立确认；真实风险组继续拒绝。不预先承诺能新增多少合格构建。
7. **通过以上验证后再穷尽位点对和安排三点补盲。** 原历史、时间、模型与旧资格全部保留，完整新合同以独立配置记录。当前87/728远未穷尽，不能宣称全空间不可能达到80%。

本轮审查的工程结论是：计数、证据来源与反例重放通过；科学结论是：原合同正式覆盖仍17.660761%，shadow为79.381610%，目标未达成。最优先处理公共证据否决逻辑，不能靠提高rSASA暴露菜单数量或继续盲追加重复替代。
