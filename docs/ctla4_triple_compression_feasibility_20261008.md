# CTLA4 两组双点合并为三点的可行性审查（2026-10-08）

## 问题、范围与判定

审查两个具体压缩：构建体 1+2 → **A61W/T67R/M134R**，构建体 4+6 → **S55F/S101R/I102R**；若两组同时压缩，六项面板会变为四项。编号均为 UniProt P16410。审查使用保存的 `coverage_scan_v3_preview` 同一 1AH1 链 A 可靠 WT 表面，面积分母 6,874.363277945836 Å²、10,199 个采样点和 12 Å 表面测地扫描合同。第六项 S55F/I102R 已有合格的保存双点证据，但原正式交付仍是五项；本文的**六项基准是新的反事实审查基准**，不修改正式结果。

按已确认的 `frozen_baseline_information_compression_v3_1` 压缩合同，三点自身必须通过稳定性、五对生产模型、各位点同四次直接变化、独立 null 以及三个精确双点对照。替换整块面板还须保持扫描覆盖≥80%、相对压缩前六项累计损失≤1 个百分点、最大连通盲区不增加、几何区分指标和删除任一构建体后的最差覆盖不下降。最后两项是本项目的实验设计约束，并非蛋白折叠的物理定律。

## 4+6 和两组同时压缩的必要上界

无需猜测未计算三点的 mask，也能检验单构建失效合同：最差覆盖是删除面板中任意一项后的最小值，因此**删除新三点本身**给出了最差覆盖的上界。

| 拟压缩面板 | 假设失效并删去 S55F/S101R/I102R 后留下 | 已保存 mask 并集 | 相对六项基准最差覆盖 75.98% |
|---|---|---:|---:|
| 仅 4+6 → 三点 | 1、2、3、5 | **73.9350%** | 至少下降 2.04 个百分点 |
| 1+2 与 4+6 同时压缩 | A61W/T67R/M134R、3、5 | **74.3720%** | 至少下降 1.60 个百分点 |

这两个上界与新三点的稳定性、实际扰动大小无关。即使 S55F/S101R/I102R 在正常条件下覆盖整个表面，一旦它失效，上述剩余构建体的覆盖也不会改变。因此 **4+6 单独压缩及两组同时压缩都不可能通过当前单构建失效鲁棒性合同**。尚缺的精确双点对照和三点自身模型也是独立的正式证据缺口；为本次压缩判断继续运行 FoldX、场和 null 不会改变上述结论。S55F/S101R/I102R 是否能稳定表达或保持折叠，仍是未回答的构建体层面问题。
