# v4 实验效应到抗原表面的映射算法

状态：方法规则及部分产品接口已实现；表面图快照、FCS/样本/门控/QC 数据库、FlowKit 全事件执行、孔/批次效应 API 和页面已接入。人工审核的 gate-analysis 结果可写成不可变 effect-analysis artifact，并关联冻结图/映射哈希。四格 Fab×抗原交互、结构图交互层、真实 activation fixture 和前瞻校准仍未完成。本文的阈值是可配置的分析规则，未经本实验体系的前瞻校准。

## 1. 可回答的问题

一次流式实验给出的是指定门和阈值下的**报告阳性细胞比例**。突变体相对 WT 的下降是这个实验条件下的功能效应，既不是结合亲和力变化，也不是该残基与抗体直接接触的概率。单浓度流式读数会受饱和度影响；要估计亲和力或 EC50，需做浓度梯度并拟合剂量反应曲线。[Tite-Seq 原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5268739/)。

单点扫描结合表达控制，能产生可映射到结构的“突变敏感位点”；文献中抗体逃逸突变在结构表面聚集，但也可能通过折叠、构象或受体功能间接影响读数。[Greaney 等，2021](https://pmc.ncbi.nlm.nih.gov/articles/PMC7676316/)；[Starr 等，2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7418704/)。即使突变位于真实界面，也可能不降低读数；界面外突变也可能降低读数。[实测突变与复合物结构比较](https://pmc.ncbi.nlm.nih.gov/articles/PMC7100438/)。因此本算法输出“功能敏感区域/位点及证据等级”，不输出“结合接触概率”。

## 2. 不可变输入和分析单位

每个分析版本固定：FCS SHA-256、样本归属、门控版本、阳性阈值、排除窗口、QC 审核、构建体序列、v4 `residue_mapping.csv`、`probe_sectors_v4.json`、`surface_graph_v4.json` 及三者哈希。表面图快照保存可及节点、边的 Å 权重、分区归属、结构和映射文件哈希；分析时核对哈希，不从新版结构或新版分区静默重建位置。

统计单位依次为**孔 → 独立批次 → 构建体/探针 → 分区或单点**。一个孔内的数万个事件只改善该孔比例的测量精度，不能充当数万个独立实验重复。不同批次不能先合并事件数。原始事件、门控及对照信息遵循 [MIFlowCyt](https://pmc.ncbi.nlm.nih.gov/articles/PMC2773297/) 的可追溯要求。

## 3. 先计算效应，再做结构定位

### 3.1 每孔与每批次

孔 `w` 的阳性率为 `p_w=x_w/n_w`。保留 `x_w`、`n_w`、`p_w`、门控父层级、门控版本及 QC 状态。一个批次内，对同一条件的合格技术重复取**孔比例的中位数** `P_b(condition)`；各孔权重相等，不按事件数加权。展示每孔点和技术重复的范围/MAD，避免中位数掩盖分歧。只有人工批准的 `PASS` 或 `PASS_WITH_OVERRIDE` 参与主计算；`HOLD/EXCLUDE` 留在审计表。

对同批次、同抗体、同剂量、同细胞系和同门控阈值的突变抗原 `M`、WT 抗原 `W`、相应阴性对照 `N_M/N_W`：

```text
绝对效应 Δ_b = 100 × [P_b(M) − P_b(W)]                单位：百分点
校正窗口 A_M,b = P_b(M) − P_b(N_M)
校正窗口 A_W,b = P_b(W) − P_b(N_W)
保留率 R_b = A_M,b / A_W,b
下降 D_b = 100 × (1 − R_b)                           单位：%
```

阴性对照相同且设计允许共享时，`N_M=N_W`。抗体突变实验改为固定 WT 抗原，比较突变 Fab 和亲本 Fab，并各自使用适用的 NC。**不得把抗原突变效应与抗体突变效应混在同一结构图层**；后者映射在抗体 VH/VL 轨道。

只有 `A_W,b>0` 且事先配置的对照窗口 QC 通过，才计算 `R_b/D_b`。建议启动配置把最小 `A_W,b` 设为 0.10（10 个百分点），并对接近 0/100% 的读数显示动态范围警示；此值是待实验标定的工程阈值，不能当成文献公认标准。未通过时 `R_b/D_b=null`，保留原始比例与 `Δ_b`，分区不得用该批的下降百分比着色。负保留率、保留率大于 1 和负下降值保留原数，不截断，另附 `OUT_OF_RANGE_INTERPRETATION` 标记。

例如 `WT=70%`、`突变=35%`、`NC=10%`，则 `Δ=-35` 个百分点，`R=(0.35-0.10)/(0.70-0.10)=0.417`，下降 `D=58.3%`。页面必须同时显示这三个量；只显示“下降 58.3%”会隐藏基线和对照窗口。

### 3.2 独立批次和不确定性

对相同构建体、抗体及可比实验条件，主估计为**批次效应的中位数**，即 `median_b(D_b)`，同时报告各批 `D_b` 与一致方向的批次数。至少 3 个独立批次时，按**整个批次**有放回重抽样，重算中位数，给出描述性 95% bootstrap 区间；固定随机种子、迭代次数和分析版本。3 批次的区间很粗，应展示原始批次点，不能用细胞事件的二项置信区间替代生物学重复。只有技术重复时仅报告观察值及孔间离散度，不称“显著”。如果跨批次出现方向相反，显示 `HETEROGENEOUS`，不以中位数掩盖。

若同一构建体有多个不同氨基酸替换，每个替换先各自汇总，随后才能做“位点概览”。预先定义主要读数、方向、最小有意义效应阈值和复测规则。示例初始阈值为 `D≥30%` **且** `Δ≤−10` 个百分点，但这些仅作复测排序，不是验证表位的自动判定。

### 3.3 双突变交互

完整 `亲本/突变 Fab × WT/突变抗原` 四格可在每批计算百分点尺度的差中之差：

```text
I_b = [P_b(A*,G*) − P_b(A*,G)] − [P_b(A,G*) − P_b(A,G)]
```

四格都要有合适 NC、QC 和同批门控。`I_b` 是该功能读数尺度上的交互，既不能证明两个残基直接接触，也不能用来生成 GRASP RPR；阳性率靠近 0/100% 时尤其容易产生尺度效应。交互与抗原单侧定位分层显示。

## 4. 表面映射是受约束的归属，不是数值扩散

对每个抗原构建体，用 WT 序列逐位比对，得到真实改变的 UniProt 位点集合 `M_c`。通过 `residue_mapping.csv` 校验 WT 氨基酸、结构坐标和链号。`M_c` 中未映射或不在图节点的位点保留在实验记录，标为 `UNMAPPED/NOT_SURFACE_NODE`，不得投影到最近表面残基。

按每个抗体**分别**生成以下三层，原始组合效应只出现一次：

| 图层 | 输入及归属 | 颜色含义 |
| --- | --- | --- |
| 直接观测 | 标记 `M_c` 中每个已映射位点；点开可见整个构建体的效应 | 构建体级读数；多点探针的每个点都带 `COMBINATION_EFFECT`，不是位点效应 |
| 分区效应 | 仅当 `M_c` 所有位点都在**同一** v4 分区且该探针 QC/窗口通过，才归该分区 | 先取每探针的跨批中位下降，再对该分区不同探针取中位数；附探针数、独立批次数和范围/区间 |
| 单点效应 | 仅 `|M_c|=1` 的构建体，或后续有成对去卷积实测且明确标为条件效应 | 位点旁按替换列出下降、百分点差、批次一致性和展示证据；概览不替代替换级数据 |

跨分区组合仅以连线/边框同时标出涉及的分区，状态 `CROSS_SECTOR_UNASSIGNED`，不进入任何分区的数值中位数。单分区组合也只证明“此组合扰动了该区域的读数”，**不把 D 均分给残基**。同一探针的重复批次先汇总为一个探针效应，再参加分区中位数，避免批次数多的探针主导颜色。分区展示各探针中位数的范围；仅当面板有至少 3 个可比且匹配的独立批次时，才按批次整体重抽样、每次重算探针及分区中位数，给出描述性分区区间。缺失探针导致批次面板不匹配时不强报区间。未测试分区灰色；已测试但无下降用独立的中性色，避免与未测试混淆。

只有组合探针且没有能区分组内位点的单点或去卷积实验时，结论停在分区。即使可拟合稀疏线性模型，也不在这类数据上自动求“每位点贡献”：组合效应、表位接触、折叠损伤和非线性互作不可由一个终点唯一分解。Starr 等在密集突变库中使用全局上位性模型分解多突变观测，但该数据包含广泛单突变覆盖和表达/结合双读数，不能直接移植到稀疏探针面板。[原始研究方法](https://pmc.ncbi.nlm.nih.gov/articles/PMC7310626/)。

## 5. 表面图只用于可视化范围

对一个**合格单点**观测位点 `i`，在冻结的加权表面图上求 Dijkstra 最短路 `d_G(i,j)`。可选渐淡图层：`K(d)=exp[-d²/(2×5²)]`，`d>12 Å` 或不连通时为 0。下降图层的透明度为 `clip(D_i/100,0,1)×K(d)`，负下降（信号增加）另用颜色显示；图例标 `VISUALIZATION_ONLY`。多个点可取最大透明度，不相加为“预测下降”。图节点外、结构缺失位点和跨不连通表面永远不被染色。带宽 5 Å 和截断 12 Å 是 UI 参数，不是抗体 footprint 半径，也不进入位点证据等级、分区中位数或 GRASP 约束。

## 6. 证据等级和审计

证据标签按**观察设计**定义，避免把效应大小误当接触概率：

| 标签 | 最低依据 | 允许的结论 |
| --- | --- | --- |
| `UNTESTED` | 无合格实验 | 无实验结论 |
| `REGION_PERTURBATION` | 同分区组合，窗口/QC 合格 | 该组合使该区域相关读数变化 |
| `SITE_SENSITIVE_SINGLE` | 单点替换，窗口/QC 合格 | 该替换使读数变化；非直接接触证明 |
| `SITE_REPLICATED` | ≥3 独立批次、方向一致，并有展示及构象/功能对照通过 | 复现的功能敏感位点；仍非直接接触证明 |

`PASS_WITH_OVERRIDE`、历史 Myc、同期 Myc、构象对照、低结构可信度、SASA 分歧分别做正交标签。历史 Myc 不能升级 `SITE_REPLICATED` 的同期展示条件。只有历史 Myc 或人工豁免时可展示效应，但最高显示 `FUNCTIONAL_CANDIDATE_WITH_LIMITATION`，不可写作“已验证表位位点”。若同一区域多个抗体/对照同时下降，应加 `POSSIBLE_GLOBAL_DISPLAY_OR_FOLDING_EFFECT`，优先补同期表达与构象控制。预测 DiscoTope/Paraplume 与实测层分别展示，不改变实测等级。

## 7. 导出与验收实例

每条分区/位点记录至少保存：`antibody_id`、`construct_id`、`mutation_set`、`batch_ids`、`well_ids`、`x/n`、各批 NC/WT/突变比例、`Δ/R/D`、区间算法及随机种子、QC 与豁免理由、门控/分析版本、映射和图快照哈希、结构位点、证据标签。GRASP IR 只能由审核通过的具体残基记录导出；分区组合、视觉渐淡和跨分区探针不能自动生成残基 IR。历史 Myc 豁免须随 IR 一起导出。

最小验收表：

1. `WT=70%、M=35%、NC=10%` 得 `−35 pp、R=0.417、D=58.3%`；`WT≤NC` 时只有原始值/百分点差。
2. 同一探针三个批次不合并事件；批次效应 `[20, 40, 60]%` 的主估计为 `40%`。
3. 两位点同分区组合只改变分区层；跨分区组合两区均不获分区效应；单点位点层仅来自真正单点构建体。
4. 图不连通时渐淡不跨组件；更改结构/映射/图哈希须拒绝复用旧分析版本。
5. `PASS_WITH_OVERRIDE` 可追到理由，历史 Myc 不能被显示为同期测量；从 FCS 重建同一分析版本得到相同的效应和导出。
