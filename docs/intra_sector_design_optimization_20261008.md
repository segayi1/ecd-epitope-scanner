# 分区内突变组合设计优化

## 目标、范围与依据

用户要求覆盖增益最高优先，每个显示分区至少有一个合格或带失败原因的近门槛组合，随后提供完整建议并要求尽量覆盖整个分区。已复算该建议的CTLA4数据，并按以下规则实施。不假定相邻残基一定低收益或不稳定。

范围为常规V4.1生成、beam、全局假设池、FoldX排队、逐区建议及导出。分区几何、科学门槛、主预算和FoldX42上限不变；物理coverage_scan专用路径不变。生成空间互补优化已实施，新增组合尚未经过昂贵模型评分。假设配额保留更多独立组合可能提高SPURS multi工作量。

## 原实现的机制

1. 位点池按可及性、化学扰动、单点SPURS排序并截断；局部高分位点可能聚集。候选仅限制最大测地跨度24Å，没有内部互补性条件。
2. beam和局部shortlist先按单点正ΔΔG之和、表位先验排序。同一对位点的最多9种氨基酸排列可能占满候选名额。
3. 全局假设配额与FoldX短名单仍偏低风险双点；后续覆盖优先选择不能找回未保留或未评分的组合。
4. 双点没有低阶收益比较；三点存在现有高阶增益门控，但部分旧路径使用假设响应/膨胀覆盖代理。
5. `geodesic_0`直接面积只统计不同突变残基。两个相邻位点也各自增加面积，因此该指标无法识别扰动邻域重叠。

## 分区内的新设计规则

### A. 先覆盖不同位置，再探索替换

保留现有单点资格、保护残基和SPURS菜单。按位点集合分组，每组先留一个代表，再轮换加入替换方案，防止同一位点组垄断beam和短名单。保留表位支持/回退与假设配额，所有截断采用确定性排序。不能用位点间距离硬拒绝相邻组合，也不能以最大距离替代覆盖收益。

### B. 区分直接面积和邻域互补

生成位点池先最大化窗口覆盖；beam在覆盖比例/内部增量/初始风险的Pareto前沿中先保留不同位点集合，按覆盖比例、边际面积、重叠等排序。全局身份去重后统一全表面分母，避免任意重叠窗口决定全局排名。逐区建议优先9/12/15Å等权平均本区面积覆盖，接着内部边际、重叠、直接面积及风险；主面板仍以新增直接面积优先，互补性用于同分选择。三尺度均导出，不挑最大半径充当真实扰动证据。

真实扰动证据可用时，采用同一参考网格、阈值和unknown合同上的组合实算mask；不能用单点mask并集充当组合mask。主报告分别显示直接面积、几何邻域代理和已验证计算扰动面积，禁止混用分母或unknown。

### C. 评估第二/第三点的增量

双点与其两个精确单点比较，三点与三个精确双点比较：`ΔA = A(组合) - max A(低阶对照)`。优先选择新增覆盖较大的组合；相同收益选风险更低、点数更少者。只有几何代理时该值用于候选排序与审查，不凭空新增科学放行阈值。真实mask缺失记unknown；需要独立模型/对照才能声明功能互补。

现有三点门槛保留；未来若将其替换为真实面积增益门控，必须明确单位、分母、阈值和全部精确对照，另行完成合同及回归，不暗中改变正式资格。

### D. 让评分预算评到互补组合

FoldX42预算不扩张。在真实显示分区/科学假设的公平配额内，优先分配给不同位点集合，再以覆盖增益、互补支持、风险排序。三点的精确双点对照仍需占用可审计预算。若候选本身未经过组合SPURS/FoldX，保留为证据缺失，不能把单点风险求和当作组合稳定性。

### E. 逐区推荐与失败解释

沿用已实施的通过优先、无通过者选最近门槛者。显示实际涉及本区的位点、跨区位点、覆盖指标定义、重叠代理、组合模型值与阈值及失败原因。近门槛者单独待审查，不计正式面板或Stage2。完全无安全候选的区域必须说明不可构建原因，不能捏造组合。
