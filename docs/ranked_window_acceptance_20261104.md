# SPURS 窗口预评分：真实案例验收

## 范围与输入

采用 ordinary_site_first_v2 / ranked_window_v1，窗口最多 1024 个唯一组合，每批最多 64 个，每例上限 10000；SPURS multi 在案例内常驻。FoldX 上限 300 槽，先 3 槽、符合条件再追加 7 槽。PD1 和 CTLA4 顺序运行，输入分别与旧案例 5212c397d9c3、bb76740c3073 相同；新案例为 3e9cfce5c346、8db3f2dad7df。PD1 输入含配套 AF3 confidence。新案例使用独立目录，生产源码快照 SHA256 为 `2bc8728358481a51a70b67a446beeb2ea9ccf2b3dc77695d0434972dd9bcda67`。

## 验收与边界

真实模型短测对 64 个组合比较逐次加载与常驻，最大绝对差为 0；1024 个唯一组合按 16 批完成，抽样单项与批次一致。比较容差 atol=rtol=1e-4，0.5、1、2 分档未改变；退出时身份核验完成。这不是对全部蛋白或所有组合的等价性证明。

两例计算完成，按 10000 上限重跑结果检查均 PASS，检查包括协议、面板签名、正式展示资格、FoldX 配对证据、技术错误和导出一致性。CTLA4 原检查为 NEEDS_REVIEW：旧检查器固定 1000 上限，而本次实际 1024；已保留原始结果，并以明确传入 10000 的检查器生成独立复核结果。PD1 区域原则覆盖为 INCOMPLETE：队列完成 21/24，3 条无合法候选；CTLA4 覆盖 COMPLETE，完成 24/24。完成队列不代表实验有效。
