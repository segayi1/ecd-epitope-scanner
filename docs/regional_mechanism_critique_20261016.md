# 逐区机制推荐的批判修订（2026-10-16）

## 采纳判断

用户建议指出了值得检查的偏好和证据缺口，但“成熟、无偏”“保证朝向抗体”“双模型排除系统偏差”“无合格组合说明结构脆弱”都超过现有证据。帕累托前沿之后必须选择工程偏好；SASA说明静态溶剂可及性，不能保证抗体可接近；稳定性模型的一致也不是折叠、表达或结合实验。

| 建议 | 判断与实现 |
|---|---|
| Max-min可能压低机制专一替换 | 采纳。原实际为五组，芳香性与疏水性均分，并无独立芳香性一票否决；改组内max，减少要求每个候选同时覆盖各类化学变化的压力。 |
| 近邻异向变化应受净变化惩罚 | 采纳诊断，拒绝通用惩罚。净变化为零不说明空间电荷分布不变，也不能证明形成盐桥或结合扰动消失。 |
| 高暴露时放宽0.5到0.8–1.0 | 先审计，不自动放宽。0.5是SPURS单点默认筛选上限，不能混成所有模型或组合的统一安全线；本项目尚无支持暴露分段阈值的实验校准。 |
| 位点距离应硬设8–18Å | 不采用硬窗口。增加WT几何与方向提示，保留原跨度及组合确认；静态主链距离不能推出突变侧链冲突。 |
| W/Y引入导致聚集 | 增加芳香替换与引入计数供复核；不把计数当聚集预测，也不以反芳香配额强行改变结果。 |
| 只有一个比较对象也可称稳健 | 修正。敏感性明确当前比较范围和数量，少于两个为比较对象不足。 |

三篇原始研究的摘要/记录支持上述证据边界：

- [Delgado等，FoldX force field revisited（2025）](https://pubmed.ncbi.nlm.nih.gov/39913370/)在其验证集中报告约1.25 kcal/mol RMSE；不能把本项目0.5阈值当结构安全置信区间，也不能把该误差直接赋给本项目某个突变。
- [Di Savino等，表面电荷分布与复合物形成（2021）](https://pubmed.ncbi.nlm.nih.gov/33646750/)支持电荷位置与局部环境的重要性；该体系不是本项目的抗原抗体，不能直接校准本项目双点效应。
- [Wen等，芳香疏水区域暴露与聚集（2018）](https://pubmed.ncbi.nlm.nih.gov/29694051/)在特定蛋白、添加剂和机械应力条件下观察到关联；不证明单个W/Y替换必然聚集或发生非特异结合。

本轮核读范围为PubMed摘要及记录，未声称读完上述全文。机制分组变更是本项目的工程选择，不是上述论文证明的新最优算法。

## 新选择规则

策略族保留`regional_mechanism_pareto_v1`，新排序独立标记`mechanism_channels_v2`。原始六项绝对变化均值、逐位有符号变化、最小暴露和缺失掩码均保留；原始轴上的帕累托支配定义不改。

冻结候选参考分布后，各轴做不同取值的序数归一化，常量轴不参与。组内取最大效用：

1. 暴露组：最小相对侧链暴露度。
2. 电荷/亲疏水/氢键组：电荷、疏水性、供体、受体轴的最大归一化效用。
3. 体积/芳香组：体积和芳香性轴的最大归一化效用。

组间仍按最弱组、次弱组依次最大化，再用局部几何、预测风险和ID稳定破同分。完整证据优先，不同缺失模式不交叉填零；His相关未知仍保存。D→R可以由电荷与体积进入竞争，不要求它也改变芳香性。此规则不保证降低所有数据集的芳香族占比，也不保证D→R优于D→Y。

搜索多样性以六个原始非零化学轴独立保留，不与这三个折中组混为一谈。双点/三点配额、亲本上限、单点和组合模型门、序列检查、24Å表面跨度、模型分歧门、FoldX预算及表位注释角色保持原合同。

敏感性新增去除芳香性轴，并重算该变体的前沿；其余变体继续重算对应前沿。比较对象是当前同阶且同缺失模式的保留/确认候选；不是全空间或实验稳健性。若只有一个候选，sensitive/robust均为未知，状态为INSUFFICIENT_COMPARATORS。

## 诊断和导出

`signed_change_summary`记录电荷/疏水轴的带符号净变化、绝对变化总和，以及`1-|净和|/绝对和`的代数反向比例。任一成员该轴未知则整项未知；全无变化时比例不适用。数值不进入排序或准入，也不表示物理自中和。

`local_interaction_diagnostics`记录WT Cα距离、相反方向变化、<10Å近邻异向电荷/疏水变化、<6Å及>25Å距离提示。阈值仅为公开的诊断约定，不是新的科学门。Cα缺失时不推断距离；不伪造Cβ、突变rotamer、盐桥、碰撞或溶剂重排。另列F/W/Y替换数与非F/W/Y→F/W/Y新引入数，供溶解性、聚集和非特异结合实验复核；计数不包括His，不能与包含His的芳香性描述轴混用。

`resource_audit.single_threshold_audit`按当前实际SPURS配置检查REVIEW窗口，列所有窗口内替换及其他排除原因、除此单点评分档位外是否合格、rSASA/相对侧链暴露>0.6数量和未知数量。统计单位是替换方案，非位点数；同时保存去重位点数。REVIEW不进入默认正式候选。区域CSV现在同步保存resource_audit与实际sensitivity，避免只有嵌套JSON而扁平列缺失。

在线/离线共用渲染，旧结果无新ranking_version时不套用新分组解释。新页面显示诊断不参与排序、WT距离定义、阈值不放宽和敏感性比较范围。
