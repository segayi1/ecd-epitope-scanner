# 逐区机制帕累托推荐：实现与验收

本文件记录2026-10-15的原排序与冻结验收。后续新结果使用带版本标记的机制组内最大效用折中；当前方法及批判修订见[2026-10-16说明](regional_mechanism_critique_20261016.md)。历史任务不自动重排。

## 范围和版本

新常规任务默认策略为 `regional_mechanism_pareto_v1`。目标是每个实际显示区独立给出一个可解释的工程测试代表，或明确缺口。新路线读取全量合格单点证据，不受旧8/12位点和每位点3种替换的菜单限制。旧全局路线、全局主面板目标、构建预算和物理预览合同保留；新增候选可能改变最终全局入选结果。历史结果没有新版本字段时沿用旧显示，不自动重排。

DiscoTope在新逐区路线仅作注释，不参与候选生成、准入、排序、验证优先级和同分判定。这里的不变性测试固定显示分区和候选池；旧全局路线和上游假设构建仍保留原有表位先验语义，不能据此声称整个流水线不依赖DiscoTope。

## 证据和决策规则

1. 相对侧链暴露 = 孤立目标链原生侧链SASA / 同坐标孤立残基侧链SASA。两次使用同一重原子集合、1.4Å探针、960采样点和Tien/DSSP半径。不补全原子或移动坐标；保存分子、分母、状态和方法。缺失侧链/无效SASA保留未知，现有总rSASA资格规则不变。
2. 六项描述是电荷、体积、疏水性、芳香性、氢键供体和受体的名义变化；单点保存符号，组合轴使用逐位绝对变化均值，暴露目标使用最小值。His相关电荷/供体/受体保留未知。这些描述不表示结合能，不假设组合效应可加。
3. 每区每阶数每种缺失掩码单独求帕累托前沿。完整证据优先；不完整证据先按缺失数量、再按确定的掩码顺序分层，仅在同层比较机制效用，避免把不同维度的向量误当可比。
4. 原始合法候选形成冻结参考分布。每轴以不同取值的分数秩转为效用，常量轴不参与。五组为暴露、电荷、体积、疏水/芳香、供体/受体；后两组组内等权。优先前沿，逐次最大化最差组、次差组效用，再按局部几何互补、组合稳定性风险和候选ID确定代表。它是公开的工程偏好，不是学习得到的效应预测器。
5. 敏感性检查序数/极差归一化、最小/平均暴露及逐组移除。每个变体重新计算对应原始轴的前沿，并比较实际代表是否变化。参考分布冻结；记录实际比较的候选数。生成阶段不计算全量变体，确认和推荐阶段才对当前候选集计算，避免重复计算且不把未评估记成稳健。

## 搜索、预算与安全

- 全部合格位点与替换进入双点枚举；每区保留20双点，同时保留强扰动种子、最低预测风险代表、不同位点组和机制多样性。最多12个双点亲本扩展所有其他合格位置，三点按物理身份合并并保存亲本，保留10三点；双/三点名额不互借。
- 既有24Å表面测地跨度和完整canonical序列检查保留；组合新建或破坏糖基化序列也检查，不以两个安全单点推断组合安全。按排序后的canonical位点/突变AA合并共享物理构建，合并来源与目标假设，共享一次组合评分。
- 审计可用/保留位点组数量、4双点/2三点的请求及缺口、原始参考集规模、最低风险代表和亲本。三点空间搜索是有界扩展，不宣称穷举全局三点。
- 送模型前复用现有canonical↔连续输入编号映射。SPURS multi、FoldX、两模型差异和高阶增益门均不放宽。合格双点优先；三点替换双点须原始平均轴支配最佳双点且通过原高阶增益门，或没有合格双点且自身满足门槛。
- FoldX共享默认预算60物理组合，每组合5次。先逐区一个专属机会，再不同位点组机会，然后有希望的三点和原有补充；预算不足或没有可确认候选时保留缺口。

## 展示和导出

每区默认显示工程代表，原覆盖优先方案保留为备选，并提供风险、机制极值和跨区覆盖对照。相同构建合并卡片和原则。通过稳定性门但扰动证据不全、接近门槛和没有安全组合分别显示，不能把缺失当作失败或零。

主卡显示直接映射突变位点面积、本区12Å邻域估计覆盖面积/比例和未覆盖面积。详情保留9/12/15Å、重叠、边际、完整未覆盖列表、逐位带符号描述、参考分布和敏感性。分母为本区合格表面映射面积；几何邻域不是实测抗体接触面积或扰动范围。

在线与离线共用渲染。单点CSV、区域CSV/JSON、候选JSON、表面证据CSV和方法报告同步保存新字段，延用原清单与ZIP打包。历史没有这些字段时显示历史语义。

## 已发现并修复的问题

- 不再使用未经校准的暴露×表位×化学综合分数；缺失His轴不补零。
- 反例锁定“序数排序方向反了”“跨阶比较被阶数限制锁住”“共享候选合并丢失机制证据”“移除维度仍用旧前沿假稳健”等边界。
- Bio.PDB `deepcopy(residue)`复制父级完整20模型NMR结构，造成耗时膨胀。改用脱离parent的实体`copy()`。冻结1AH1前5个完整侧链新旧坐标、SASA分母与暴露比差值均为0，收据 `workspace_data/regional_mechanism_20261015/sasa_copy_equivalence.json`。
- 固定评分的旧测试显式绑定旧策略；新策略增加按实际请求返回评分的端到端测试。几何门测试提供真实有限的双模型夹具；点缓存测试按BLAS精确状态是否一致判断复用，物理实现和科学门未改。
