# 逐区合格推荐合同（2026-10-25）

用户明确当前主要结果应为4–12个显示分区，各区独立给出不同设计原则下通过计算门槛的推荐。全局精简面板不是这些逐区推荐的数量上限。

## 行为

- 常规V4的长度分区函数统一使用4–12区软偏好；每区表面残基目标继续根据实际分析链长度取7/8/12，不按binder标签区分。连通、最小面积、唯一归属与直径限制仍优先，确实无法达到范围时保留例外诊断。物理预览原合同保留。
- 每区保留现有机制主代表、覆盖、较低预测结构风险、电荷、体积、疏水/芳香、供体/受体和适用的跨区补充原则。同一组合满足多个原则时合并标签。机制路线的DiscoTope仍仅作注释。
- 最终原则备选只接受正式资格通过者。没有通过者时写`unavailable_principles`，保存接近门槛候选的追踪编号及实际失败/缺失门；不把未确认或未通过项称为合格推荐。主代表的近门槛记录保留，页面默认折叠到审查详情。冻结旧结果中的未通过备选也按相同规则归入审查详情，不改原保存数据。
- 全局面板仍可作为附加精简选择；其预算移入次要折叠信息，新建界面说明它不限制逐区结果。逐区推荐先展示，计算审计及精简面板随后展示。网页请求显示区软上限改为12，中英文提示和脚本/i18n缓存同步。
- 评分前及三槽追加确认期间用`confirmation_planning=True`保留未评分原则候选的验证优先级；最终推荐与保存评分重放默认只接受合格原则备选。80唯一组合、60 local/20 global和300配对槽总预算不变。没有证据的原则可能保留缺口，不能保证所有原则都有合格结果。
- 展示补充描述符使用单点记录副本，避免把描述字段写回源候选的科学单点记录；模型分数、资格及原始文件不改。CSV增加`unavailable_principles`列，与JSON中的失败/缺失证据保持一致。
