# 小分区归并修复验收（2026-10-08）

## 原因与修改

旧实现将最少4残基/50 Å²作为贪心整区合并的触发条件，最终仅验连通性和直径。拆分后没有合法整区并集时，1–2残基小区仍正常返回。此前审查见 [历史版本审查](ctla4_small_region_version_audit_20261008.md)。

在现有有界整区整理之后，新增确定性的最近可行邻区归并及边界重分配。按残基数、面积、最小位置选择未达标区；邻区按两区最短全局表面测地距离排序。保留包含小区的合格连通部分，回溯分配被挤出的边界残基，完整方案通过后提交。受影响的其他小区可因接收边界节点而达标，随后重新识别未达标区。公共函数最终强制完整唯一覆盖、连通、直径、最小残基数及面积。

扩展到PD-L1完整流程时发现，仅将冲突节点送到其他现有区域会漏掉合法方案。增加受体边界重建回退：所有完整归并均失败后，确定性搜索小区与受体的合法连通子集；受体剩余部分也必须连通、至少4残基/50Å²且有界。两部分完整通过才提交，区域数保持不变。新增13节点分支回归证明5/5/3可重建为5/4/4；无须删除节点或扩大阈值。

成功返回仍为 `list[V4Sector]`；新增可选诊断字典。失败抛出带诊断的 `PartitionConstraintError`；engine保存 `partition_diagnostics_v4.json` 与不含显示归属的原图，停止候选生成。显式 `sectors=None` 且关闭显示归属才允许导出未分区图；空列表不能冒充已完成覆盖。诊断及策略版本 `connected_bounded_v3` 在图、display、manifest间一致。
