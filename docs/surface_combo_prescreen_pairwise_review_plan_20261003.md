# 组合预筛与三点二阶外推：审查及修改计划

日期：2026-10-03。范围：所提供“验收进度评估”对话缓存片段，结合当前工作区源码及SPURS原论文/官方实现。片段在路径预测处截断，未取得完整后文，不将未见内容视为已审查。本文件仅为计划；不修改算法、冻结检出、配置、账本或正在运行任务。

## 1. 审查结论

1. 组合前规则与SPURS单点预筛科学上合理，但当前已经存在：`joint_design_v4/evidence.py::build_single_evidence`形成具体替换资格，`compressed_options`仅保留eligible替换，然后生成组合。优先补一致性、审计与缓存，不再增加一次重复SPURS扫描。
2. 当前权威政策自动排除引入C/P/G，保护原C/G/P及既定结构风险。不能采纳片段中“引入Pro仅warning”或“无替换时放回高风险项”来改变正式池。风险项可保留在独立诊断池，不获得目标资格。
3. SPURS实现接受多点输入，不是原生接口最多双点；但高阶模块的训练、调参与性能验证主要是双突变。三点输出需明确外推身份。
4. 二阶展开三点公式成立于一致的WT参考、物理量/符号及忽略三阶项的假设；不是三点已验证预测器，也未证明优于原模型三点外推。
5. 当前单点checkpoint与multi checkpoint不同。直接混用其预测值可能把模型基线差异计入epistasis；应检查multi模型自身单点预测与原single模型一致性，并分别保存基线来源。
6. 当前 `_annotate_stability` 在只有部分single存在时仍求sum，且可能把它用于epistasis。修改应要求每个组成单点均存在且有限；NaN、Infinity和缺失单/双点均为未知，不能补零。
7. 当前V4菜单显式保护已有糖基化位点/序列基序；`stability.py::changes_sequon`已有完整序列替换检测。需核查并统一具体替换路径，尤其新建基序、邻位改变、组合协同新建/破坏基序。上述核查尚不能等同于已证明所有运行样例出现该缺陷。

## 2. 三点诊断的数学合同

三个具体替换A、B、C的完整、同身份证据为S_A/S_B/S_C及D_AB/D_AC/D_BC：

```
T0 = S_A + S_B + S_C
epsilon_AB = D_AB - S_A - S_B
epsilon_AC = D_AC - S_A - S_C
epsilon_BC = D_BC - S_B - S_C
T2 = D_AB + D_AC + D_BC - S_A - S_B - S_C
paths = [D_AB+S_C, D_AC+S_B, D_BC+S_A]
```

真实三点量仍包含未知三阶项。三个paths各自仅保留一对相互作用；其range/std只表示模型内部非加和诊断，不能作为置信区间、误差界或三阶项上界。三个path完全一致也不能证明三阶项为零。

外推误差中的单/双点预测误差共享模型、结构及训练集，不能按独立误差传播。没有外部三点稳定性数据时，不输出校准后的稳定概率或数值置信界。

字段建议：additive_baseline、pairwise_extrapolated_score、three_pair_epistasis、path_scores、path_spread、direct_multi_triple_score、single_baseline_source、evidence_complete、extrapolation_status、missing_evidence。不得用T2覆盖现有spurs_multi_ddg字段。

## 3. 分阶段修改

### P0：资格及证据一致性

- 复用现有单点扫描、阈值和缓存；输出各步骤的位点数/具体替换数/排除原因，以及压缩菜单前后数量。REVIEW保持现有正式政策，不趁优化改成合格。
- 具体替换与完整组合序列都应用权威保护政策、N-X-S/T变化检查；单点筛查不能代替组合基序检测。
- 缺失或非有限SPURS结果拒绝正式资格并输出未知原因；单点和必须双点全部完整才生成T0/T2。
- 统一输入结构、序列、编号映射、checkpoint、代码及参数hash；导出菜单冻结身份。去重具体替换与双点组合，保留来源。
- 不以“FoldX/SES成功”作为真实稳定标签调SPURS阈值；四例仅用于工程比较，阈值变化须独立的有标签稳定性验证。

### P1：二阶诊断，先shadow再决定是否排序

- 对每个值得复核的三点请求三个精确双点子集，合并为一次去重批量请求；复用已保存合法double分数，不额外加载三次大模型。
- 审计单模型与multi模型的单点输出差异。先保存混合基线及同multi基线两套诊断；未评估可比性前不将模型差异解释为物理epistasis。
- 保留当前direct multi三点分数，并行保存T0/T2/paths及缺失原因。初版shadow不改变候选资格、排序或确认预算，以便同候选比较。
- 若后续启用排序，采用版本化开关；只安排真实建模优先级，不凭三点外推分数硬排除尚可真实核验的组合。用固定资源预算检查会否遗漏高价值三点。
- 不使用max(paths)、路径spread或任意安全裕量声称具有保守误差界。没有支持数据时只能称工程风险诊断。

### P2：真正的提速点

- 先记录SPURS加载/encoder/head、FoldX、SES/SDF、null、导出/APBS的实际wall time、调用数和峰值内存；预筛已存在，不能以100→50的组合数量算式宣称现流程节省75%/87.5%。局部跨度、去重、批次cap会改变收益。
- 批量double请求，按候选数量控制head批量内存。检查multi worker按阶调用model是否重复encoder；若重复，研究保留WT特征并批量head，须与原实现逐候选等价、形状/设备/随机性审计。
- 常驻模型worker仅作为后续选项：独立进程、权重/设备锁、资源回收、超时和异常重启合同清楚后再启用；不能为省加载占满两条病例队列内存。
- 优先维持合法缓存、1→3→5增量模型、5→10→20 null、最大重复失败不重算及最终面板才APBS。组合数量减少不必然减少匹配null成本。
- 两条病例队列继续并行，GPU推理保持现有限流；记录CPU/RAM/磁盘峰值。共享缓存必须原子写和身份一致，不能仅按蛋白名复用。

### P3：真实三点与目标验收

- FoldX组合稳定性仍执行原正式门槛；不能把FoldX当作实验真值或证明三阶项很小。
- 三点保留三个精确双点实际结构/场对照、原额外覆盖收益门槛、五对真实组合、逐位同组4/5贡献及真实场再优化。
- 80%定义仍为既定面积加权hard扫描机会，实际改变面积单列；4–12项、每项2/3不同位点、goal/search独立、未知不填零，均不因预筛改变。
- 新证据语义实施时生成新版本冻结检出，在阶段边界交接；旧运行结果/账本保留，同批预算不退款。输入和阈值完全未变时合法原模型/原场可复用，资格重新审查。

## 4. 验证与实施顺序

1. 回归：缺一single或double、NaN/Inf、不同checkpoint、排列不变、重复位点、基序新建/破坏与组合协同、与保护政策一致、批量去重。
2. 数学反例：单点加和/T2正确；三个path相同但存在任意三阶项，必须仍显示三阶未知；缺失不得降为0。
3. 保存输入重放：同结构类型/confidence/映射、同候选及预算，比较旧行为与shadow诊断。不能同时换候选池和方法再声称由新公式提高覆盖。
4. shadow方案至少比较T0、T2、原multi三点与FoldX一致性、拒绝原因和实际覆盖收益；一致性不是准确率，没有实验标签不宣称三点精度提高。
5. 从隔离检出父目录用项目venv测试科学/API/导出/UI及两层manifest/ZIP；报告字段保持预览证据等级。
6. 先完成P0，再P1 shadow；只有实际瓶颈和等价验证支持才实施P2 encoder/常驻worker。P3保留原真实验证合同。
