# 网站 UI 重设计与验收

## 用户确认的设计

保留七步向导，采用浅色科研工作台；1366×768、1440×900 笔记本优先。结构相关步骤突出画布，结果相关步骤加宽右栏，切换步骤保留视角和选择。序列默认紧凑摘要，按需展开完整比对。改造覆盖首页、实验项目、PD-1 抗体页、分区/CTLA-4 结构页外围，以及后续离线报告。用户通过 grill-me 问答后明确批准实施。

## 实现范围

- `web/workbench.css` 提供共享配色、导航、焦点与减少动画设置；各页保留自身的布局和科学展示规则。
- 首页将新建任务、上传和高级参数收进原生对话框；保留原表单字段、验证及 API 请求。七步增加当前步语义、前后导航与方向键操作。左侧为标题、画布、紧凑序列摘要；右栏随步骤调整宽度。
- 默认显示 WT 全结构，避免载入后自动聚焦局部构建体。显式选择组合仍联动结构、序列及评分；分区选择退出组合遮罩、定位当前分区，并显示可键盘操作的选中态。序列可展开、复制和键盘定位。图例缩短为分区编号，悬停保留全名。
- 实验项目统一项目导航与选中态，结构模块移到校验材料之前；主要操作表单按需展开，逐行 QC 保留行内操作。完整校验来源可展开，宽表格使用内部滚动，不裁切项目内容。
- PD-1、分区表面和 CTLA-4 页面整理标题、工具与画布比例，统一导航。分区报告生成器内联共享 CSS；不重新运行科学生成器或覆盖历史科学数据。
- 离线模板保留七步、单个 3Dmol 画布和自包含资源，采用同一布局方向、紧凑序列、键盘选择与复制反馈。新逐区任务的说明区分逐区建议和正式主面板，历史任务保留原说明。

## 修复过程中的回归

1. 旧 walkthrough 只认六步且要求双序列始终展开；按当前七步及已确认的紧凑摘要更新。WT 默认不再自动选构建体，折叠耐受步骤应检查明确的未选中状态，而不是要求空评分表具有可见高度。
2. 新标题样式曾向说明段落传播大字号；恢复标题/正文层次。实验页不能给全部表单统一套折叠容器，行内 QC 应保持表格操作，输出与主表单的相邻关系也应保留。
3. 手机实验详情曾用 overflow-x:clip 遮住宽内容；改为内容换行、表格内部滚动及保留行内布局，移除根容器裁切后仍通过尺寸验证。
4. Molstar 的 `plugin.isBusy` 是布尔值；早期截图等待误读成 `.value` 导致验证超时。最终截图等待真实空闲状态，并在场景绘制完成后保存。

## 边界
