# V4.1 下一阶段实施与验收记录

日期：2026-09-30 至 2026-10-01。默认 total rSASA 仍为 0.25；没有重新训练模型。

## 已实施的批次

1. **资格分离**：native total rSASA 定义暴露；侧链 SASA 只作描述。独立记录坐标资格、位点初筛及具体替换审核。高暴露 Gly 的零侧链面积不阻止表面资格，Gly/Pro 骨架风险及原有具体替换保护政策仍保留。低 pLDDT 不被解释为折叠损坏：内部几何可用位点可以进入复核池，复核池不能进入正式面板；不可靠末端仍退出三维几何。
2. **三层假设**：保留全部 raw footprints；同中心形成 family；确定性 complete-link 合并 inference hypotheses。core/nominal/extended 工程权重 1/0.7/0.3；adaptive 来源独立保留。合并条件为 weighted Jaccard≥0.75、中心残基图测地距离≤6 Å、法向夹角≤60°、相同连通分量和结构域、兼容可靠性；合并 nominal 连通，测地直径≤30 Å、Cα直径≤24 Å。缺少法向、中心或合法预测 PAE 不合并。显示区域仍采用独立的 26/18 Å规则。
3. **全局候选池**：物理身份由位点与替换决定，来源假设合并；双/三点独立生成、shortlist，四点 exploratory。每个 inference hypothesis 尽量保留2个双点、1个三点；60/order 容量随必保留配额扩大并记录，缺口包括完全为空的 order。正式和复核池独立。扰动向量继续是几何/化学 proxy。
4. **自适应面板**：新任务默认 V3，最少目标4、常见目标7、硬上限8。signature distance 固定 √8 归一化；逐步记录覆盖、平均/最小分离度、近距离假设对、风险、冗余和净增益。没有正净增益允许早停；4以后继续要求绝对信息增益≥0.02、相对≥0.05，并改善分离度或减少未解决对。重复假设使最小距离为零不会阻止其他有效改善。近距离连通组仅为待解析组，并输出具体对。
5. **版本与交付接口**：V1/V2 保持固定预算及旧选择路径。显式新预算优先；旧 max_primary_constructs 单独使用时保留固定上限。API 预算顺序验证、UI 分层解释、实际运行策略 manifest、完整 ZIP、三阈值真实重放脚本均已实现。benchmark 只完成输入与隐藏真值隔离规范，未开展真实回顾性 benchmark。

## 限制与诚实解释

- 保守合并后假设仍很多：现有 surface centers 约7 Å间隔，合并上限6 Å，因此相邻 family 压缩有限。没有为了达到数量强行降低阈值，未覆盖/待解析结果逐层记录。结构定位收益需后置 benchmark 验证。
- CTLA4 的3个入选不意味着其余正式通过候选均不稳定；在当前风险/冗余工程权重下没有正净增益。最少4为目标，不是填充指令。预测结果不能保证实验表达或结合效果。
- 真实重放进程启动后只进行了等价搜索缓存优化、旧 profile 兼容性、审计文案/策略字段和缺失 PAE 防护修正；CTLA4 为实验结构，PD1 此验证 PAE 均有效。源码哈希在导出时采样，不能单凭该哈希声称进程加载了后续编辑版本。独立 Git 检出回归另行核验提交完整性。
- 本地服务重启命令被自动审批拒绝，原因为 blocked by policy。现有服务进程尚未确认加载新代码；需要正常重启服务。独立 API TestClient 已验证新预算入口。
- 当前仓库开始时含大量未提交功能。本次提交只包含 V4.1 及其结构、worker、颜色和导出必要依赖；实验工作台、流式和其他功能修改保留在工作树。独立检出发现已有 pipeline 引用未提交链识别函数的缺口，必要依赖另行提交。
- 不保证正式推荐数量；结构映射正确性、保护政策、证据和失败原因完整才是验收依据。
