# 面向抗体表位定位实验的流水线改进方案（2026-09）

## 实验背景

用户持有一组已筛选抗体，目标是定位其针对的膜蛋白抗原表位：输入蛋白 → 输出一组设计合理的
突变组合构建体 → 通过抗原-抗体结合力下降（配合折叠/表达对照）归因表位。

在此用途下，构建体是**测量仪器**而非单纯的安全突变集合。设计要优化的量是
`P(结合丢失 | 构建体, 表位位置)`：既要求突变不破坏折叠（保阴性可解读），更要求
"如果表位在扰动范围内，构建体足够强"（保阳性可检出）。

## 文献校准的关键参数

| 事实 | 数值/结论 | 来源 |
|---|---|---|
| FoldX ΔΔG 精度 | R=0.53–0.69，RMSE/SE ≈ 0.85–1.1 kcal/mol（S669/S2648） | PMC6158775；PMC11879241（revised force field） |
| 语言模型 zero-shot 突变效应预测 | ESM-1v 在 41 个 DMS 数据集上与监督 SOTA 相当，单序列即可打分 | Meier et al., NeurIPS 2021 |
| 构象表位尺度 | 平均 ~15 残基，75% 落在 15–25 残基；界面 BSA ~600–900 Å²/侧 | Kringelum et al. 2012 (PMC3461403)；Reis et al. 2022 (PMC9329859) |
| 结合热热点 | 富集 Trp/Tyr/Arg（"O-ring"包埋）；ΔΔG 分布不均 | Bogan & Thorn 1998, JMB |
| 构象表位常跨结构域边界 | 表位不遵守结构域配额分区 | Kringelum 2012 界面几何 |

推论：
1. 单点 FoldX 门限 +0.46 kcal/mol ≈ 1×RMSE，对暴露位点过严（字母表过度收缩 → 探针变弱）。
   改为**暴露度联动门限**：rSASA≥0.35 → +0.80；0.25–0.35 → +0.60；组合门限维持 +2.0。
2. 补丁（patch）尺度按抗体足迹设定：**测地半径 13 Å，8 残基下限，目标 15–25 残基**。
3. 突变字母表按 WT 类型定向（见下），组合必须含至少一个**锚点突变**。

## 方案总览（已全部实现）

### A. 分区：结构域配额测地分区 → Fab 足迹尺度补丁枚举 + 表位先验

- 保留原表面测地图（Cα≤12.5 Å 连边、跨域 +4.0 / 跨二级结构 +1.5 罚分）。
- 种子 = 暴露最优起点 + farthest-point（图测地）采样，直到所有合格残基落在某种子
  测地半径 ≤13 Å 内；残基分配给最近种子；<8 残基补丁并入最近邻。
- 补丁允许跨结构域（跨域罚分仅体现在边权，不做配额强制）。
- 每补丁计算**表位先验**（权重见 `config.py`）：平均 rSASA、低接触数（外凸度）、
  环区占比、糖屏蔽惩罚、天然界面小加分、保守性可变性（有保守性数据时）、
  `cell_surface` 实验形式下膜近端强惩罚。
- 先验排序分 tier（HIGH/MEDIUM/LOW）。补丁数超过 `maximum_regions`（默认 8）时
  合并先验最低的空间相邻对——保持"Stage-1 面板预算"语义。
- 输出 `coverage_plan`：HIGH 补丁要求 ≥2 探针（主+备选），MEDIUM ≥1，LOW 与最近
  LOW 补丁合并或**声明为盲区**。

### B. 突变字母表定向 + 锚点突变 + 组合全枚举

- 每位点 19 替换仍全量打分（saturation_scan 兼容），但按 WT 类型给出 `menu_class`：
  - 大侧链 WT（W/Y/F/R/K/M/I/L）→ Ala 优先（去热点/去大侧链）；
  - 小侧链 WT（G/A/S/T/D/N）→ Trp 插入优先（Ala 对小残基几乎无效）；
  - 带电 WT → 电荷反转（K/R↔E/D）。
- 锚点突变 = 电荷反转 或 W/Y/F→A。Stage-1 组合必须含 ≥1 锚点（补丁内无可用锚点
  时降级并留警告）。
- **破坏势 D(r,m)** = 暴露度 + 体积落差 + 电荷反转 + 热点消除 + 芳香插入（权重见
  config），与稳定性风险构成双目标；**组合选点已升级为帕累托优化**（2026-09-05，参照
  EpiSweep 的双目标思想）：全枚举后取 (min Σrisk, max ΣD) 的非支配前沿，主探针取膝点
  （max D/(risk+1.0)，1.0 为 FoldX 单点噪声尺度），备选探针取激进端；λ 权重不再参与
  组合选择，由实验折叠对照结果校准。前沿逐点写入 `pareto_fronts` 审计。
- 组合搜索从"每位点 top-1 贪心"改为**全枚举**：每位点 ≤3 个 FoldX/共识通过替换 ×
  ≤4 位点 ≤ 81 组合，逐组合校验（成对间距 ≥5.5 Å、含锚点、ΣΔΔG ≤ 组合门限）后
  取目标函数最优。 FoldX 批量复评能力不变。

### C. Stage-2 去卷积 + 表位定位实验计划

- 每个 Stage-1 探针自动生成：**单点拆解**（`STAGE2_SINGLE`，每位点一个构建体）和
  最多 2 个**确认性双点组合**（`STAGE2_PAIRWISE`，用于单点均不丢、组合才丢的冗余表位）。
- `analysis["epitope_mapping_plan"]` + methods_report 新章节输出：
  - 面板覆盖矩阵 `panel_coverage_matrix.csv`（构建体 × 补丁，值 = 补丁内 10 Å 内
    被扰动残基比例）；
  - 决策树：Stage-1 丢失模式 → 表位补丁归属 + 置信度（覆盖冗余度）；
  - 盲区清单（无探针覆盖的补丁，显式声明"未测"而非"阴性"）；
  - Stage-2 预设清单。
- 多抗体复用：同一面板给全部抗体共用；相同丢失模式 = binning 证据。

### D. 新证据线

- **保守性**（`conservation.py`）：UniProt REST 取同基因 reviewed 直系同源（≤8 条），
  PairwiseAligner 全局比对，逐位置保守分 = 同源同一比例（≥3 条才计分）。低保守
  （可变）位点 → 表位先验加分、功能风险减分。离线/失败 → None 并声明。
- **ESM zero-shot**（`esm_scores.py`）：opt-in（`ECD_ESM_MODEL` 环境变量 + torch/esm
  可导入），对候选替换算 log-likelihood ratio 进入共识；不可用时优雅降级并留痕。

### E. 实验形式参数 + 全长导出

- `PipelineRequest.assay_format = "cell_surface" | "purified"`（API 字段同步）。
  `cell_surface` 时膜近端补丁先验 ×0.5 并在报告标注 IgG 可及性限制。
- `original_cds` 可解析为全长 CDS 时，导出 `full_length_coding_sequences.fasta`
  （全长膜蛋白编码序列，突变按 UniProt 绝对位置应用）；无 CDS 时导出
  `full_length_protein_sequences.fasta` 供基因合成公司反向翻译。细胞流式实验需要
  全长构建体，ECD 片段导出仅适用于纯化蛋白实验。

### F. 顺带修复（此前审阅确认的缺陷）

- P0：`WAITING_FOR_AF3_UPLOAD` 恢复时不回填 accession → UniProt 作业 AF3 上传后
  必然 FAILED（jobs.py）。
- 服务重启后遗留 QUEUED/RUNNING 作业永久非终态 → 启动时标记 FAILED("interrupted")。
- `write_json`/下载改原子写（tmp+os.replace）；4xx 不再重试。
- 7 处子进程调用捕获 `TimeoutExpired` → 降级为 None+诊断，不再炸穿作业。
- FoldX 批次中位数改**按行名归组**并校验行数，杜绝错位。
- 输出阶段只写一遍（structure_sha256 提前计算），DNA Chisel 不再重复执行。

## 兼容性

- 前端消费的 region/design 字段全部保留；新增字段向后兼容（前端忽略未知字段）。
- `region_id` 仅挂在 Stage-1 主设计上，Stage-2/备选设计用 `parent_design_id` 关联，
  避免前端"分区→设计"映射被覆盖。
- 主设计状态沿用 `RECOMMENDED_LOW_PREDICTED_RISK`；新增状态：`ALTERNATE_PROBE`、
  `STAGE2_SINGLE`、`STAGE2_PAIRWISE`、`ANCHOR_UNAVAILABLE`（警告级）。
