# 细胞表面膜蛋白模式：优先级修改计划

## 1. 适用范围

本计划针对当前真实实验场景：全长膜蛋白细胞表面表达后进行抗体结合检测。纯化 ECD 不属于本轮验收范围，cell_surface 继续作为默认实验模式。

实施状态（2026-09-15）：P0、P1 和 P2-1 连续膜可及性已落地；DBSCAN 敏感性分析保留为后续独立验证工作。

核心目标是提高结构证据完整性、细胞表面可及性解释、突变归因能力和大型任务计算效率。

## 2. 优先级总览

| 优先级 | 工作包 | 主要目的 |
|---|---|---|
| P0 | conservation 证据修复 | 消除当前排序中的证据缺失 |
| P0 | 膜近端/界面风险语义 | 防止把低可及性误读为不可测 |
| P0 | 输入和统计一致性 | 修复 PECAM1 输入及统计矛盾 |
| P1 | 小 ECD 分辨率增强 | 避免 CD3D、CTLA4 过度合并 |
| P1 | engineered mismatch 降级 | 降低结构背景不一致风险 |
| P1 | FoldX 组合搜索优化 | 降低大型目标运行时间 |
| P2 | 连续膜可及性模型 | 由距离分层升级为几何模型 |
| P2 | DBSCAN 敏感性分析 | 评估分区稳健性，不改变生产默认 |

## 3. P0：必须优先完成

### P0-1 修复 conservation

当前 5 个成功目标均出现 conservation 未计算、同源数不足或 KeyError，补丁先验实际没有使用可靠进化证据。

修改：

- 检查 conservation.py 的 UniProt gene 字段和查询结果字段映射；
- 对缺少 gene、sequence、accession 的记录跳过并记录原因；
- 分别记录查询失败、空结果、比对失败、同源不足和缓存损坏；
- 保存 orthologs_used、查询条件、比对参数和逐位点分数；
- 增加状态：computed、insufficient_orthologs、query_failed、invalid_payload；
- 前端和报告明确显示“保守性证据缺失”，不得只显示中性分数。

涉及：conservation.py、retrieval.py、pipeline.py、exporting.py、新增 conservation 回归测试。

完成标准：

- 至少一个目标成功生成逐位点 conservation；
- 模拟 KeyError、空结果和网络失败不会中断主流程；
- conservation 可用性在 JSON、manifest、报告和前端一致；
- 修改分数能导致先验或排序发生可验证变化。

### P0-2 统一柔性末端统计

P16410 的摘要显示排除 19 个残基，而 warning 显示 16 个，说明不同模块使用了不同统计口径。

修改：

- 分区阶段只生成一次柔性末端排除数量；
- summary、warning、methods report 和前端全部读取同一字段；
- 区分无坐标、无二级结构和柔性末端排除；
- 线性表位扫描数量单独保存；
- 历史结果读取时提供兼容性说明，不覆盖原始文件。

完成标准：同一作业所有出口数值一致，柔性末端仍能进入独立线性扫描列表。

### P0-3 支持基因符号输入

PECAM1 是基因符号而非 UniProt accession，当前直接请求会得到 HTTP 400。

修改：

- 输入层识别 accession、gene symbol 和 protein name；
- gene symbol 查询必须带物种，默认提示确认 Homo sapiens；
- 多个候选时返回选择，不静默选取；
- request.json 和 manifest 同时保存原始输入及规范化 accession；
- 无匹配或多匹配时不进入计算阶段。

完成标准：PECAM1 能解析为 P16284，并保留原始输入；旧 accession 调用保持兼容。

### P0-4 明确膜近端和界面风险

当前 cell-surface 模式将膜近端区域标为 assay_accessible=false，但仍生成探针；界面突变也可能进入主探针，容易产生错误解释。

修改：

- 将“不可及”改为“预测可及性降低”；
- 膜近端探针保留为低优先级或可及性对照；
- 界面位点增加 interface_risk 或 function_risk=high；
- P04234 等界面比例高的目标尽量生成非界面替代探针；
- 前端、CSV、JSON 和报告统一显示风险语义。

完成标准：用户能区分常规推荐、低可及性保留和自动排除；P04234 的界面风险可追溯。

## 4. P1：近期完成

### P1-1 小 ECD 分辨率增强

CD3D 只有 2 个补丁，CTLA4 只有 3 个补丁。当前按 ECD 长度预算，不能保证小 ECD 的空间分辨率。

修改：

- 补丁预算同时考虑表面残基数和表面面积；
- 小于 100 aa 或少于 40 个表面残基时启用重叠补丁；
- 重叠补丁保持 8–15 个核心残基；
- 柔性末端单独输出线性 alanine-scan；
- Stage-2 优先增加单点去卷积，不盲目增加多点组合；
- 报告增加空间分辨率等级。

完成标准：小 ECD 有可解释的重叠补丁或单点定位方案，且不因强行增加区域而生成过大组合。

### P1-2 engineered mismatch 邻域降级

Q9NZQ7 有 1 个、P16410 有 4 个 engineered mismatch。整体结构可准入，但 mismatch 附近的 SASA 和 FoldX 结果可能不代表目标序列。

修改：

- 保存 mismatch 的 UniProt 位置；
- mismatch 周围 3–5 个残基标记为 engineered_neighborhood；
- 默认不作为主探针，除非没有替代；
- 必须使用时标记 REVIEW_REQUIRED；
- 报告同时显示结构序列和目标序列；
- 后续增加目标序列重建结构复核。

完成标准：mismatch 邻域在前端、CSV 和 manifest 可追溯；无 mismatch 目标结果保持不变。

### P1-3 FoldX 组合搜索优化

大型目标产生约 56–72 个 engine batch，组合枚举是主要耗时来源。

修改：

- 拆分候选发现、主探针计算和完整 Pareto 前沿；
- 先执行确定性结构/化学规则；
- 默认每个位点最多 2 个候选进入 FoldX，第三个保留备用；
- Stage-1 使用 5-run median，Stage-2 单点默认 1-run；
- 对结构哈希和重复突变启用缓存；
- 批次写入输入哈希、完成数、失败数和进度，支持中断恢复；
- 超过组合上限时保留代表性 Pareto 候选。

完成标准：P06729、Q9NZQ7 运行时间下降，主探针在容差内一致；中断重启不重复计算；FoldX 失败不伪装为 kcal/mol。

## 5. P2：后续增强

### P2-1 连续膜可及性

当前膜近端判定依赖到膜锚点的距离分位数。后续应结合 TM 螺旋、膜平面法向、残基到膜平面的距离、侧链方向、凸出度和糖链遮挡，输出 0–1 连续可及性分数。没有可靠膜方向时降级使用旧模型，并在报告中说明。

### P2-2 DBSCAN 敏感性分析

DBSCAN 不替换生产分区。增加 geodesic、dbscan、hybrid 三种研究模式；DBSCAN 使用测地距离或受欧氏跨度约束的距离，初始参数 eps=10–13 Å、min_samples=3–5。审计噪声残基、簇大小、测地直径、跨域比例，并比较区域 overlap、coverage 和设计数量。只有基准集验证后才考虑 hybrid 进入研究模式。

## 6. 实施顺序

输入规范化 → conservation 修复 → 统计字段统一 → 膜近端/界面语义 → mismatch 降级 → 小 ECD 分辨率 → FoldX 性能 → 连续膜可及性 → DBSCAN 敏感性分析。

P0-1 和 P0-4 会改变科学排序，必须在重新生成正式实验面板前完成。P1-3 主要改善性能，但不得改变既有主探针定义和审计顺序。

## 7. 回归测试矩阵

测试至少覆盖：accession/gene symbol 输入、多物种匹配、无结构和低覆盖结构、mismatch、多链 AF3、conservation KeyError/空结果/缓存损坏、小 ECD、柔性末端、膜近端、界面高比例、主/替代探针、FoldX 缓存/超时/空输出/中断恢复、summary 与 warning 一致、FASTA/CDS/GenBank 一致、实时与离线前端风险标签。

## 8. 重新评估和完成定义

P0 完成后，用同一批 8 个目标重新运行，比较可完成比例、conservation 成功率、膜近端和界面风险标记、补丁数量、突变类型比例、mismatch 邻域进入主探针数量、FoldX 批次数和耗时。新版结果不得覆盖旧版结果。

最低完成标准：

1. 每个作业都有明确结构证据等级；
2. conservation 缺失不会被静默当作正常中性值；
3. 膜近端和界面风险语义统一；
4. 小 ECD 有可解释的定位分辨率；
5. mismatch 邻域可追溯并默认降级；
6. FoldX 支持缓存、进度和恢复；
7. 所有统计字段一致；
8. 新旧版本结果可以逐项比较。
