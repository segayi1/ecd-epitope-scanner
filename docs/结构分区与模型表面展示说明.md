# PD-1、PD-L1 与 CTLA-4：结构分区、模型表面展示与复现说明

> **用途。** 本文把当前工作区三次已完成的 `joint_v4_ml` strict 运行，与网页端的结构表面/分区展示实现关联起来，说明：分区如何生成、网页如何将它们映射到三维模型、三个靶点得到什么结果，以及如何在本机复现和审查。它描述的是用于突变探针粗定位的**表面 sector（显示归属）**与可重叠的表面假设，不把它们称为实验确认的抗体表位。

## 1. 结论摘要

- 三个审查对象均使用 `joint_v4_ml` strict 模式并输出 7 个显示 sector：PD-1（P16410）、PD-L1（Q9NZQ7）和 CTLA-4（Q15116）。
- 主网页默认使用 PDBe Mol* 的 `molecular-surface` 表示；结构本体先按通用层级着色，随后按 sector 着色。点击分区、残基、设计或 footprint 会以确定的优先级覆盖原颜色。
- V4 的 sector 是覆盖和候选组织用的**互斥显示投影**。它由显式溶剂表面图上的测地 Voronoi 分区得到；真实的候选表面假设可重叠，保存在 V4.1 原生 footprint/hypothesis 输出中。故“某个残基在 R3”不表示它只可能属于一个潜在抗体结合表面。
- PD-1 的 7 个 sector 均没有本次记录的几何 QC 标记；PD-L1 有 R1、R5、R7 的跨度超限标记，应在解释和后续候选门控时审阅；CTLA-4 的 R7 标为低表位先验、不可自动设计，不能被误读成优先推荐区域。
- 网页展示的是**输入 WT 结构坐标**。设计表面模式中的红色是 WT 位点位置，标签才是替换字母；它不是突变后原子构象预测。

## 3. 分区方法：数据语义和科学边界

### 3.1 进入分区前的结构与残基条件

1. 选择目标链，核验 canonical/输入序列与结构坐标的映射。
2. 保存 UniProt 位置、author residue number/插入码与 label 编号。所有外部预测 worker 使用连续的规范化位置；`residue_mapping.csv` 是回溯编号的权威文件。
3. 在规范化结构上下文计算 native SASA/rSASA 和侧链 SASA；默认的突变表面资格阈值为 `rSASA ≥ 0.25` 且侧链 SASA `≥ 20 Å²`。
4. 保护/风险审计包括二硫键、糖基化/PTM、坐标缺失、低可靠度或埋藏位置。功能界面不会静默删除，但会保留风险标记。
5. ProCaliper SASA/rSASA 是 cross-check；它不代表独立的有限尺寸 Fab 可达性计算。DiscoTope 只提供软表位倾向先验。SPURS single/multi 和 FoldX 负责稳定性证据与组合门控。

因此，高 SASA、sector 颜色或较高先验都不能单独推出抗体可达性、结合变化或真实表位归属；最终归因还需要表达、折叠/构象控制和功能读出。

### 3.2 V4 sector 的生成

当前实现依赖显式溶剂表面图，而不是线性序列切段：

1. 高暴露残基成为表面图节点；真实表面边界残基可作为受限测地路径中继，避免阈值在连续表面上造成假孔洞。
2. DiscoTope 局部高分位置形成 epitope island（仅先验）。每个物理表面连通分量先获取中心，其余中心以确定性最远点策略选择。
3. 经过至多 8 轮 minimax-medoid 更新后，根据测地距离进行 Voronoi 归属。
4. 过小区域合并到共享边界最多的相邻区域；显示区域保持表面连通与覆盖。
5. 对每个 sector 审计表面积、可设计面积、测地/欧氏直径、连通性、先验与质量标记。

默认 QC 比较阈值为测地直径 `35 Å`、欧氏直径 `30 Å`。超限时保留区域和覆盖分母，但记录 `GEODESIC_DIAMETER_EXCEEDED`、`EUCLIDEAN_DIAMETER_EXCEEDED` 等标记；不会通过删除低先验残基让结果表面上“合格”。没有 epitope island 的区域标为 `LOW_EPITOPE_PRIOR` / `COVERAGE_ONLY`，用于覆盖审计而不是自动优先设计。

### 3.3 sector 与 Surface V2 footprint hypothesis 的关系

- **显示 sector：** `regions.json`/`analysis.json.regions` 内的互斥基础归属。网页将每个残基的 `region_id` 映射到一种 sector 颜色，便于审查。
- **可重叠 footprint：** V4.1 的候选抗体兼容表面假设，主要由 12 Å 与 adaptive-area footprints 构成，9 Å 为 core、9–15 Å 为 boundary。一个残基可同时属于多个 hypothesis。
- **设计面板：** 用探针 × footprint 响应代理矩阵及稳定性门控选择；响应是测地距离和化学扰动的规则代理，**不是**结合变化概率。

网页的 `surface_v2.footprints` 下拉框（当结果中提供该字段时）可单独将一个 footprint 显示为洋红色。网页 sector 色与 footprint 色不可混为同一个生物学结论。

## 5. 主网页如何呈现模型表面和分区

### 5.1 运行时调用链

1. 页面由 `web/index.html` 定义，含 `#viewer-molstar` 与 `#viewer-beads` 两个画布，默认选择“表面”。
2. 提交真实作业后，网页通过 `POST /api/jobs` 或 `/api/jobs/upload` 创建任务；使用 SSE `GET /api/jobs/{id}/events` 获取状态。
3. 作业完成后，`GET /api/jobs/{id}` 返回结果；服务在结果中补入 `structure_url=/api/jobs/{id}/files/ecd_structure.cif`。
4. `app.js` 的 `adoptResult()` 保存 `residues`、`regions`、`designs` 等结果，随后 `ensureViewers()` 初始化渲染器。
5. `renderer.js` 的 `MolstarView.init()` 用固定版 PDBe Mol* 插件加载 mmCIF；初始化完成后关闭 distance fog 和 far-plane clipping，避免放大时结构淡出或被截断。

主页面需要通过 FastAPI 服务访问；它依赖 `/assets/*`、`/api/*`、作业结构 URL 和真实作业时的 SSE，不能等价地作为独立 `file://` 页面运行。

### 5.2 表示模式与着色顺序

默认 Mol* polymer 表示是 `molecular-surface`。工具栏可切换：

- **主链（cartoon）**：保留聚合物的卡通/二级结构轮廓；
- **球棍（ball-and-stick）**：便于审查原子与侧链；
- **表面（molecular-surface）**：当前分区审查的默认模式。

普通模式中，`paintMolstar()` 以如下顺序追加颜色记录；后续记录覆盖前一层：

1. 表面可及残基：蓝色 `#1565C0`；
2. 折叠风险筛选通过：绿色 `#2E7D32`；
3. 当前结构中蛋白界面：橙红 `#E4572E`，并以球棍显示侧链；
4. sector：每个 region 的 `color`，若聚焦一个 region，其余 region 变灰 `#C8CDD1`；
5. 选择的 Surface V2 footprint：洋红 `#D81B60`；
6. 当前设计/自定义突变位点：橙红 `#E4572E`，并以球棍显示侧链；
7. 当前点击的残基：Mol* 高亮黄色 `#FFD166`。

可靠性开关是独立覆盖层：它用 `structure_reliability` 状态重画所有残基并替代上述分区颜色。图例会随模式重绘。

### 5.3 设计表面聚焦模式

选择有 region 归属的构建设计时，页面自动使用表面模式并将镜头聚焦到其 envelope。该专用模式的含义固定为：

| 颜色 | 含义 |
|---|---|
| `#EEECE6` | 其余蛋白表面 |
| `#D69E2E` | 该设计所属 region 的 envelope |
| `#F0E76A` | footprint |
| `#D55E00` | 输入 WT 结构上的突变位点 |

页面 callout 明确提示：红色位置来自 WT 表面，突变标签代表设计替换，**不是**突变后原子构象或表面重建。

### 5.4 残基选择、编号与交互

- 结构着色查询优先使用 mmCIF `label_asym_id + label_seq_id`；否则退回 `auth_asym_id + auth_seq_id + insertion_code`。
- Mol* 只监听 `PDB.molstar.click`，通过 author 编号、链和插入码回查结果中的残基记录。没有把 mouseover 绑定为选择事件，避免 hover 重绘详情面板而中断自定义设计表单。
- 序列坞中的残基点击会聚焦对应结构残基；结构点击会更新位点详情、列表与序列选择。
- “珠子”替代渲染使用 3Dmol 的 Cα 球；仅真实作业可用，因为它请求作业的 `structure_for_energy.pdb`。它适合语义颜色和快速点选，不是主网页的 molecular-surface 实现。

### 5.5 离线报告的差异

离线 HTML 将 3Dmol、PDB 文本和分析 JSON 内联，支持珠子/3Dmol cartoon。它不包含主页面 PDBe Mol* molecular surface、完整的 Surface V2 footprint 下拉、可靠性覆盖或与主页面完全相同的图层优先级。因此，复核“模型表面和分区”时应优先使用主网页；离线报告适用于无网络的轻量审阅。

## 6. 本机复现步骤

### 6.1 启动服务

在项目根目录：

```powershell
python -m venv .venv --system-site-packages
$env:PIP_CACHE_DIR = "$PWD\.pip-cache"
.\.venv\Scripts\python.exe -m pip install -e . -r .\requirements-dev.txt
.\.venv\Scripts\python.exe -m ecd_epitope_scanner serve --host 127.0.0.1 --port 8765
```

打开 `http://127.0.0.1:8765`。服务设计为本机回环地址使用；不要只修改 `--host` 将其直接公开部署。

### 6.2 查看已完成的三次运行

浏览器地址分别使用：

```text
http://127.0.0.1:8765/?job=e66fb47e803d   # PD-1
http://127.0.0.1:8765/?job=95bfd808b533   # PD-L1
http://127.0.0.1:8765/?job=0ae7fa7efb65   # CTLA-4
```

在每个页面中：

1. 保持“卡通”引擎、选择“表面”表示；
2. 转到第 3 步“结构分区”，点击 sector 行以高亮/取消高亮；
3. 若有 Footprint 下拉，选择一个项目并观察洋红覆盖与镜头聚焦；
4. 在第 5 步选择设计，检查专用表面聚焦配色和突变标签；
5. 点击模型或序列中的残基，核对位点详情中的 UniProt、author 编号、rSASA、风险和分区字段；
6. 在第 4 步检查界面层，特别审查 PD-1 R2 与 PD-L1 R1/R3/R4 的非零接口比例。

### 6.3 重新运行（示例）

```powershell
# PD-L1 示例：真实运行依赖本机 V4 workers、WSL/GPU 和 FoldX 配置
.\.venv\Scripts\python.exe -m ecd_epitope_scanner analyze `
  --uniprot Q9NZQ7 `
  --design-engine joint_v4_ml --ml-mode strict `
  --max-sectors 12 --max-primary-constructs 7 `
  --output .\results\Q9NZQ7_v4
```

严格模式需要完整的必需外部稳定性证据。SPURS、DiscoTope、FoldX、ProCaliper 的 worker、许可证、GPU/WSL、超时和缓存会影响可运行性；缺少必需证据或候选未通过门控时应保留 `BLOCKED_EXTERNAL_EVIDENCE`，而非用代理分数伪装通过。

### 6.4 文件级审计清单

建议按以下顺序审计一个重跑结果：

1. `run_manifest.json`：输入、来源、结构 SHA-256、参数、工具配置；
2. `residue_mapping.csv`：规范化位置、UniProt 与结构 author/label 编号的映射；
3. `surface_evidence.csv`、`sasa_comparison.csv`：表面资格与 SASA cross-check；
4. `probe_sectors_v4.json` 和 `regions.json`：原生 sector 与网页显示投影；
5. V4.1 的 `surface_graph_v41.json`、`surface_display_regions_v41.json`、`epitope_hypotheses_v41.json`、`hypothesis_membership_v41.csv`：显式表面、显示归属和重叠 hypothesis；
6. `single_mutation_options.csv`、`candidate_combinations.csv.gz`、`combination_stability.csv`：候选和稳定性门控；
7. `selected_panel_v4.json`、`panel_coverage_matrix.csv`、`v4_scientific_report.md`：最终面板、覆盖与未解析假设。

## 8. 解释限制

1. sector、footprint hypothesis 和稳定性筛选均是实验设计与审计工具，不是实验验证的表位。
2. 当前有限尺寸 Fab/SNIPR 的真实 steric reach 未被计算；SASA、表面测地连续性和 ECD anchor-axis 不可替代该结论。
3. 主页面显示 WT 结构；突变设计不会自动生成或验证突变后构象。
4. 输入结构代表其来源实验/预测上下文。不同复合物、构象、糖链状态或膜环境可能改变可及性、界面和分区解释。
5. 网页颜色是层级化的可视化状态；在同一残基上，后覆盖层会改变颜色，不能仅从单一截图反推所有底层类别。应结合图例、位点详情和导出审计文件。
